# 응용전기전자실험(II) 현장 매뉴얼

실험실에서 폰으로 보면서 따라 하는 단일 HTML 페이지 모음.

| 페이지 | 내용 |
|---|---|
| [`/`](https://brightwindow.github.io/servo-lab-guide/) | **전송선로 · 서보모터** — 교재 Exercise 1-2(전파속도), Exercise 1(장비·소프트웨어) |
| [`/dc/`](https://brightwindow.github.io/servo-lab-guide/dc/) | **직류기** — 분권 직류기 토크-속도 특성 |
| [`/im/`](https://brightwindow.github.io/servo-lab-guide/im/) | **유도기** — 농형 유도전동기 토크-속도 특성 (교재 Exercise 4-1) |

각 페이지 공통: 교재 도판을 절차 옆에 배치, 체크박스(진행률 저장), 증상별 트러블슈팅,
객관식 20문항(즉시 채점·해설), 그림 탭하면 확대.

빌드 과정 없음. `index.html` 파일 그 자체가 페이지다.
